## 为什么TikTok运营会盯着"家宽"这两个字

普通VPS用的IP大多来自数据中心的IP段，这类IP段特征明显，容易被平台风控系统标记为"非自然流量来源"。而家宽IP（也叫住宅IP、ISP IP）是运营商直接分配给家庭宽带用户的IP，从IP归属信息上看和普通网民没有区别。对于需要长期养号、开播的TikTok账号来说，这一点直接影响的是账号的"信任起点"——同样的内容，用住宅IP注册的账号,起量速度和限流概率通常会更友好。

但要注意，家宽IP不是万能药。如果一个住宅IP段之前被大量账号共享使用过（比如某些廉价代理池），照样会被标记为高风险来源。所以选择家宽VPS时，IP是否为独享静态、是否为全新IP段，比"是不是家宽"这四个字本身更关键。

## 静态住宅IP和动态住宅IP，直播和养号该选哪种

这是很多人在挑选时会卡住的地方。静态住宅IP指的是IP地址长期固定不变，适合需要稳定登录环境的场景，比如长期养号、TikTok直播间、店铺后台管理——账号登录环境的一致性对权重积累很重要，IP频繁跳变反而容易触发异常检测。动态住宅IP则是IP池随机轮换分配，更适合批量注册、短时测试这类不追求账号长期稳定性的场景。

如果你的需求是开直播或者精细化运营一到两个账号，静态住宅IP是更合理的选择；如果是批量起号测试内容方向，动态IP的成本效率会更高。LisaHost的产品线里，美国、韩国、英国、德国、越南、香港等大部分家宽方案都是双ISP原生静态IP，只有台湾的hinet线路走的是动态IP池模式，这点在选购前值得先确认清楚。
